# پاساژگردی

سایت استاتیک RTL برای معرفی پاساژ و فروشگاه‌های ایران.

## فایل‌ها
- `index.html` — صفحه اصلی
- `admin.html` — پنل ادمین (استان/شهر/پاساژ/فروشگاه، درخت، آپلود data.js)
- `data.js` — داده
- `app.js` / `admin.js` — منطق
- `favicon.svg` — آیکون

## ادمین
1. افزودن یا **آپلود data.js قبلی**
2. ویرایش از درخت
3. **دانلود data.js به‌روز** و جایگزینی در پروژه
4. در صورت نیاز: پاک‌سازی داده‌های مرورگر

## دامنه
در `index.html` و `sitemap.xml` و `robots.txt` به‌جای `example.com` دامنه واقعی را بگذارید.
